# V18.0.0 原位升级验收记录

## 高保真替换

工程父提交为原始标签 `v18.0.0`。版本号、音频实现和大厅三个右侧入口沿用原版。此次只更新源码与资源。

| 区域 | 替换和检查 |
| --- | --- |
| 样板与机队 | 先在 Blender 离线查看歼-20 的轮廓与材质，再生成全部 23 架机体的 GLB。可驾驶机型为 4096 像素材质，任务支援机为 2048 像素。已核对各机型的三档 LOD、座舱、法线和 ORM 通道，以及 KTX2 与 Meshopt 扩展。 |
| 地形 | 将三张地图的一般采样提升到 11.71875 米，每图增加一块 5.859375 米精细区。网格和碰撞调用同一高程。高程包保留原始 1025 网格节点和机场铺装高度。岩层改用分层三平面采样与 2K PBR 图。沿岸树冠走实例化。 |
| 渲染 | 将场景和环境着色器的独立色调映射收拢到 Camera Frame 的 HDR/ACES 合成。WebGPU 使用时域抗锯齿上采样，WebGL2 使用 SMAA。增加 CAS、动态分辨率、曝光测量、分级阴影和海天共用散射查表。 |
| 武器和损伤特效 | 把贴图冲击环换成三维球形壳体与深度折射通道。烟火使用翻页图集和深度软化，导弹尾迹使用连续网格，命中有局部烧蚀贴花及瞬态灯光。残骸继续使用 Havok。 |
| 飞行和战役 | 飞行接入查表取样、气动载荷与包线控制。歼-20 追尾相机标定为约 20 米后方、6.6 米上方和 53° 垂直视角。敌机视觉补偿沿给定的 12 个距离节点计算，命中与探测继续使用物理机体。第三章的全部进场波次和结算已做模拟回归。敌机生命按原版同难度公式一次扣减 150。 |
| 图形离线检查 | Dawn/SwiftShader 执行了海面 GPU FFT 数值对照。7 次采样的最大误差为 1 个纹理量化单位，CPU 约 0.61 ms，GPU 含回读约 7.92 ms。该环境保留 CPU FFT。 |

## 待运行验收

浏览器首帧、双后端逐帧画质、真实敌机投影像素、折射效果、分辨率档位及手机 60/90 FPS 和长期内存均需运行后验证。当前 LOD 使用迟滞和距离插值。专用远距图像 Impostor、抖动式 LOD 淡入淡出、座舱水汽和 GPU 计算驱动的天气粒子仍未完整实现。

## 后续定向升级

| 区域 | 原位替换 |
| --- | --- |
| 大厅与养成 | 底部改为机库、改装、出击、任务，个人档案和设置移至顶部。删除赛季、活动、基地、仓库、科技树与手动领奖页，以及它们专用的图标、插图和样式。旧挑战移入任务，里程碑移入成就。 |
| 存档 | 沿用原存档版本与存储键。旧合金、航电板、补给箱分别折合 90、140、300 信用点。弹药容量和射速改装退回原信用点支出。保留已购装备、领过的奖励编号和基地、研发已生效的权益。达成奖励与出击结算同一笔写入。 |
| 武器与火控 | 玩家航炮、空空导弹移除弹量上限，保留原射击节奏及实际碰撞。对地挂载及敌机弹药沿用原规则。投影锁定圈驱动自动捕捉，距离与地形遮挡限制发射。统一目标供提前量计算、跟踪镜头和有限追敌辅助使用。导弹、炸弹、反制、掉头、加速和躲避用实际剩余冷却驱动径向遮罩。 |
| 机库与加载 | 更新可编辑机库和其 Meshopt GLB，减少重复设施，调整金属和混凝土响应、灯具、自发光贴图和展示镜头。加载页复用 V11 存档中的背景、金翼徽章、标题和启动恢复逻辑，百分比由 V18 真实加载阶段推进。 |
| 源码与资源验证 | TypeScript、33 项单元/模拟测试及源资产检查通过。覆盖超出旧弹量的连续发射、升级前后伤害与发射间隔、锁定边界/失锁/重捕、提前量、冷却、旧档转换和自动奖励幂等。已比对原版大厅右侧三个入口的 HTML 与相关 CSS、音频源码、现有 dist，并校验 V11 加载图像字节。 |

待运行验证还包括大厅最终曝光与构图、手机触控、HUD 遮罩、锁圈和准星的实际显示、自动追敌手感，以及浏览器 IndexedDB 存档。未执行网页构建、APK 或发布。
