# V19 Babylon.js 迁移与空战验收

## 正式运行入口

| 系统 | 实现 |
| --- | --- |
| 引擎 | `src/scene-runtime.ts` 启动 Babylon.js 8.56.2 的 WebGPU 或 WebGL2 设备。两种设备共用右手场景、HUD 和权威模拟。`src/renderer.ts` 用原生 GLB 加载器、PBR、HDR IBL、太阳光、级联阴影和分档后处理生成画面。PlayCanvas 运行依赖已移除。 |
| 飞行、武器与碰撞 | `src/flight.ts` 沿用 90 Hz 轻量六自由度、攻角和升阻力、失速与飞控辅助。`src/sortie.ts` 和 `src/contact.ts` 沿用比例制导、提前量、反制、CCD 与分区损伤。残骸由 Havok WASM 推进。战斗事件与模拟位置保持一致。 |
| 敌方战术 | `src/tactics.ts` 的层级决策先处理威胁和能量，再处理编队、拦截与搜索。共享黑板记录探测到的态势。普通规划以约 2–5 Hz 更新，评估 4–8 个候选，在 3–6 秒内检查转向、高度、地表净空和编队分离。王牌受损时可改变纵向机动优先级和再接敌策略。 |
| 海洋 | `src/ocean-solver.ts` 与 Worker 继续结合多组 Gerstner、FFT 和局部浅水扰动。`src/shading.ts` 使用原生 WGSL 和 GLSL，在两种后端以同样的波高数据绘制扩散浪纹。掠海飞沫在适合的设备使用 Babylon GPU 粒子，低画质用现有视觉池回退。 |
| 流送 | `src/terrain.ts` 从三张原有战场连续过渡到确定性种子地貌。`src/terrain-stream.ts` 的四叉树按观察距离分裂和合并，多个级别共享同一采样网格并对齐边缘顶点，避免接缝出现帘状垂面。按航向和速度预测加载附近区域，离开活动范围后释放节点。异步载入的机模按最近访问顺序回收。 |
| 纹理与声音 | 两种示范材质以本地 KTX2 和 Basis 解码器加载，原图用于兼容回退。其余存量美术继续使用原格式。喷气与加力音层从授权航空录音裁剪，结合合成音和按方向、高度与距离定位的空间冲击音。署名详见 `public/licenses/aviation-audio.md`。 |
| 存档与兼容 | 保持 IndexedDB 和本地恢复快照的旧版本键。战机、装备、改装、关卡进度、战绩和 JSON 导出继续生效。 |

## 已修复的问题

| 症状 | 根因及修复 | 核对位置 |
| --- | --- | --- |
| WebGPU 初始化失败后画布无法启动 WebGL2 | 获取 WebGPU 上下文后，同一画布不能再创建另一种上下文。回退路径换用干净画布，随后才绑定界面输入。 | `src/scene-runtime.ts` |
| 高画质启用阴影后机库无法正常出现 | Babylon 的模块化构建需要显式注册阴影组件及 WebGPU 动态贴图扩展。补齐导入，并通过启动、机库和战斗切换验证。 | `src/renderer.ts`、`src/aircraft-view.ts` |
| 海岸可见直立窄面与块边断层 | 原有接缝裙边在浅水与斜坡镜头中露出。相邻 LOD 共享世界空间格点，细级边顶点按粗级线性对齐，移除多余裙边。 | `src/terrain-stream.ts`、`src/terrain.ts` |
| 远距交战容易退化为追逐 | 规划需要感知记忆、队形和未来净空。以同一权威飞行状态估算候选路线，按威胁、能量和战术职责选择分支。 | `src/tactics.ts`、`src/sortie.ts` |
| 手机横屏难以点击聚集的关卡图钉 | 全球图被缩小时，固定大小的点击区互相覆盖。图钉按地图尺寸展开，并用引线保持真实地理锚点。 | `src/campaign-chart.ts`、`src/v7-ui.css` |

## 验收边界

- 29 项 Node 回归覆盖 60 关的启动、全部章末王牌、完成波次判胜、两枚最强空空弹的耐久下限、120 波自由空战、旧档恢复、接缝采样及战术预测频率。自动通关夹具控制敌我相对位置，实际玩家的挑战曲线仍以游玩为准。
- Chromium 软件渲染用于验证 WebGPU、WebGL2、实际画面和交互。800×360 是模拟横屏触控视口。GPU 用时可用时由引擎计数器记录，显存栏为保守纹理估算。打印的帧率来自 SwiftShader，不能推断安卓真机的帧率、功耗和发热。
- 地形当前使用世界坐标和固定网格，超远距离跨区浮动原点尚未验证。KTX2 已应用在机坪和地表两类材质，原有机队纹理保留当前生产格式。
- 安卓 60 FPS 及低性能设备 30 FPS 是目标。当前无安卓实体设备可完成长时间运行、GPU 时间和温度验收。
