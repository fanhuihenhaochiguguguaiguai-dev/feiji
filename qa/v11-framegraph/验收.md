# 《苍穹锋刃》V11 渲染与飞控验收

V10 是本次唯一实现基线。V18 的独立构建用于同机位对照。正式渲染依赖锁定 Babylon.js 9.0.0。

## 根因和改动

| 发现 | 修复 |
| --- | --- |
| 环境自定义 Shader、PBR 材质和传统后处理沿各自路径做显示变换。 | `src/flight-render-graph.ts` 统一线性 HDR 颜色和深度附件、世界绘制、太阳阴影、ACES 和 FXAA。GLSL 与 WGSL 共用环境光照公式。支持 WebGL2 直接渲染恢复路径。 |
| 帧图绘制成功后，旧首帧门控仍等待传统路径的活动相机。 | `src/scene-runtime.ts` 对帧图检查实际绘制索引与图就绪状态。直接渲染继续检查活动相机。发现在加载界面无法退出时，后台已经绘制出机库。 |
| Babylon.js 9 的旧 GPU 飞沫渲染使用 GLSL。WebGPU 冷启动会请求第三方编译器，断网后首帧无法完成。 | 拦截浏览器请求并记录 Shader 编译源，定位到 `gpuRenderParticles`。飞沫改用与爆炸水雾共用的实例池，两种后端共用相同接近水面的触发条件。FFT、Gerstner、海面高度、掠海白沫和局部扰动沿用原有模拟。 |
| 传统后处理、SSAO 重建和飞沫两套路径增加状态与拆包开销。 | 删除旧后处理生命周期、GLSL 飞沫和重复资源。无人机、战役存档、战果、挂载、音效与海面 Worker 复用 V10 模块。 |
| 高速大仰角时，原速度项会抵消迎角失速。 | `src/aerodynamics.ts` 将迎角分离和低速失速分别计算。升阻力读机型曲线，纳入侧滑、密度与波阻；飞控整合能源、过载和抬头限制。 |
| 加载图无法在真实资源等待和首帧验证过程中展示独立素材。 | 按用户参考图重制云海背景、翼徽和中文标题为三个 WebP，共 222,118 字节。进度、状态和重连按钮由启动程序驱动。 |

## 飞行动力学

固定初始条件用 90 Hz 模拟。峰值俯仰角、到达首次可测抬头的模拟延迟和高度变化如下。

| 输入 | 峰值俯仰 | 响应延迟 | 高度变化 |
| --- | ---: | ---: | ---: |
| 轻度拉起 | 15.8° | 122 ms | +35.5 m |
| 中度拉起 | 48.6° | 56 ms | +93.6 m |
| 大幅拉起 | 73.8° | 44 ms | +107.4 m |
| 大幅拉起并加力 | 73.9° | 44 ms | +127.2 m |

32 项 Node 回归、TypeScript 检查、生产构建和资产注册检查通过。战役配置测试覆盖 60 关，代表关卡模拟覆盖第一、第三和第六章。浏览器另行检查实时绘制与交互。

## 实测范围

Chromium 环境使用 SwiftShader，外部 HTTPS 请求在新版回归中全部阻断。WebGPU 和 WebGL2 均完成大厅、机库、自由空战、航炮、座舱切换、返回大厅及 60/90 设置。两条路径均载入两种本地 KTX2 纹理。

在 WebGPU 游戏中销毁图形设备后，游戏自动进入 WebGL2 帧图并重新绘制机库。WebGPU 适配器持续挂起时，也进入 WebGL2。两次均保留旧存档的信用点与战役进度。

WebGL2 上下文恢复后原页面继续绘制。持续掉线会进入直接渲染安全模式。首张地貌资源注入 404 后，恢复响应并点击重连即可回到机库。调试版 GPU 计时在恢复上下文时记录到旧查询警告。

WebGL2 回归从 IndexedDB 单独恢复旧存档。第三章测试包含三架空中敌机、10 枚起始空空导弹和 Havok 残骸下坠。自由空战约 10 米掠海时，Worker 生成 192 个白沫样本；敌军炮击命中后正常结算击落。机库还验证了两条本地录音的解码。

实际浏览器进入章末关卡并验证多波次和可操作结算。用测试注入命中验证王牌伤害，双指实测同时爬升与航炮击发，航炮备弹由 510 降至 498。清空自由空战一波后立即进入下一波，重开强度改变。

性能数据来自每段固定机位连续 7 次渲染采样。CPU 数据为渲染循环到 `Scene.render` 返回的运行时间，旧版计时边界可能不同。GPU 时间为浏览器计时查询，SwiftShader 的值包含软件渲染开销。JavaScript 堆与渲染附件估算不能代表显存占用或泄漏测试。

| 构建 | CPU 中位 ms | GPU 查询中位 ms | Draw Calls 中位 | 首次完整机库 ms |
| --- | ---: | ---: | ---: | ---: |
| V18 WebGL2 | 0.8 | 528.4 | 101 | 1,022 |
| V10 WebGL2 | 6.9 | 431.0 | 195 | 2,845 |
| V11 WebGL2 | 18.9 | 228.2 | 260 | 2,936 |
| V11 WebGPU | 20.9 | 未返回 | 243 | 3,891 |

逐帧数据见 [V18 WebGL2](./V18-WebGL2-海岸.json)、[V10 WebGL2](./V10-WebGL2-海岸.json)、[V11 WebGL2](./V11-WebGL2-海岸.json) 与 [V11 WebGPU](./V11-WebGPU-海岸.json)。V11 WebGL2 在本次样本中的软件 GPU 查询时间缩短，绘制次数及 CPU 提交时间增加。

没有接入安卓真机。60/90 FPS、WebGPU 硬件时间、温控与长时间内存表现尚未在真机验证。程序保留平台帧率上限和自适应预算，本次未加入尚无净收益数据的自定义 GPU Compute。机型气动表为适合游戏控制的归一化曲线。
