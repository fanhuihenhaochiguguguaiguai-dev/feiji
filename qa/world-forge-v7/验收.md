# 苍穹锋刃 · WORLD-FORGE V7.2

对照基线为正式发布的 V7.1，提交 `fe08e5433e7fe64ee52ccf74358f95ec4c267500`。游戏仍采用 PlayCanvas 和同一套本地存档。截图在 Chromium 中由产品代码绘制。

## 问题与修复

| 范围 | 根因 | 修复 |
| --- | --- | --- |
| 全页面 | 界面框体、按钮状态和资源展示定义分散。预备界面用静态卡片代替了已有实时模型 | 统一面板、信用点、主次按钮、焦点、禁用状态和奖励样式。出击准备与自由飞行共用一个真实机库和表单。挂载页可以检视 3D 导弹。所有游戏页面只在横屏显示 |
| 机库与全机型 | 机库、昼夜和天气共享一份反射贴图，旧贴图与太阳方向和色温脱节。蒙皮、玻璃和结构件缺乏统一的表面校准 | 按机库、晴日、黄昏、风暴和夜航切换五个 HDR 反射探针。重新校准漆面清漆、舱盖、金属件、进气道和纹理采样。机库混凝土保留潮湿反射和低金属度，高亮集中在机身 |
| 自然环境 | 云亮暗和海面反光随风场变化较弱 | 调整双后端共用着色器的云体自遮蔽与海面散射。海岸、地形、云层和实体命中延续同一世界坐标。海面与天空共享天气及太阳参数 |
| 飞行与碰撞 | 高速弹道按目标列表顺序判定，飞机移动与地形接触的竞争没有比较统一的接触时刻。坠落没有更新模型插值起点 | 比较移动机体、目标、诱饵和地表的首次接触时刻。以同一地形表面查询做弹药和机体扫掠。地表命中后不再命中水线或地形后方的目标。残骸逐帧更新姿态和位置 |
| 损伤与爆炸 | 连续损伤和粒子表现弱，最后一击常被即时结算遮掉，重命中和击毁可同时发出重复重音 | 机翼及发动机受损影响相应控制和推力，冒烟位置随受损部位变化。火花、冲击环、碎片、烟、燃烧和水花按事件叠加。保留短促击毁镜头后再结算 |
| 音效 | 航炮擦碰与重型爆炸共用一条音色 | 区分金属撞击、导弹引爆、落水和击毁音色，保留距离及方向衰减。引擎声由转速和气流分层，命中提示及混音调度与战斗事件同帧触发 |
| 清理 | 前版烟火、环境探针、未使用的参考裁片和竖屏分支继续进入打包 | 删除旧烟火与探针、6 张无调用的裁片、旧预备页重复结构和竖屏排版。资产检查覆盖发行目录与离线缓存 |

## 可重复验证

`npm run check` 检查类型，`npm test` 覆盖现有功能和新增碰撞回归，`npm run test:assets` 检查 22 个 GLB、42 个物品视觉资源、静态文件及缓存。浏览器用软件图形后端测试 800 × 360、1280 × 720、1536 × 691。393 × 852 仅用于验证旋转提示、界面隐藏及战斗暂停。

本次使用原有 22 套机体几何、机场和地形高度资产，更新它们共用的材料、光照、纹理采样和现场表现。AAA 参考图所体现的环境密度和各机型几何精细度仍有差距。碎片坠落及受损部位与玩法关联，目前未实现蒙皮任意切割或精确的结构断裂模拟。浏览器软件数据只用于可比较的回归排查，手机 GPU 性能、触控手感和长时间续航仍待真机验证。

## 验收结果

- 16 项逻辑测试通过。另行修复了固定航迹复测中发现的输入状态共用问题。机体重置只恢复自己的输入快照，调用方的操控状态保持稳定。
- 19 个界面和状态通过浏览器横竖切换回归，包括全部 16 个菜单界面、战斗、雷达和暂停。竖屏实际只显示旋转提示。战斗中转成竖屏会关闭雷达，停止任务计时及飞行音效。转回横屏后可从原进度继续。
- 22 架战机逐一在 WebGPU 载入并渲染近景网格。WebGL2 与 WebGPU 均通过实际出击、锁定、导弹发射、座舱切换及战术雷达。两种后端各记录 12 组目标投影，最大位置误差约 0.02 CSS 像素。
- WebGL2 验证了双指同时抬头与开火，航炮由 510 减至 498。独立训练关用真实导弹获胜，回到任务页可领取 150 信用点且无法重复领取。
- 固定航迹回归用实际飞行步进及武器处理触发航炮命中、单次击毁与残骸坠落，保存了命中位置及时间。Web Audio 实际进入 running 状态，共调度 17 个战斗音色事件和 15 个声音节点。该数据验证声音调度，听感和扬声器表现需在实体设备测试。
- 单任务软件 WebGL2 初轮采样中，800 × 360 大厅约 1.65 FPS，战斗约 1.66 FPS，座舱约 2.33 FPS。V7.1 基线对应约 1.66、1.98 和 2.64 FPS。实战示例绘制调用从 155 变为 158，显存报告从约 36.1 MB 变为 37.2 MB。并发测试波动更大。GPU/CPU 耗时、绘制次数、显存、分辨率、三角面和 1% Low 均保留于 `性能采样.json`。这些样本不代表手机帧率。
- 云海、雪线、岛链、贴海、黄昏和风暴海岸的六组固定初始机位均完成前后截图。大厅、机库、挂载、备战、任务和结算等界面的截屏与差异图放在 `对照/`，实机图放在 `实机/`。截图与分区平均像素误差可用于定位差异，不能单独判定美术品质。
