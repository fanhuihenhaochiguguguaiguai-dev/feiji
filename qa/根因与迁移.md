# V4.0 渲染重构记录

| 模块 | 观察和处理 |
| --- | --- |
| 引擎 | PlayCanvas 2.24.2 接管三维绘制。移除了旧 Babylon 场景、地貌、机库、模型加载、弹药和特效实现。原空战以原来的向量和四元数运算继续运行。 |
| WebGPU | 迁移时发现旧 WGSL 入口、统一变量和采样器声明会让整条绘制命令无效，浏览器出现黑屏。按 PlayCanvas 的入口签名、绑定格式、每行独立声明和纹理-采样器顺序修正。 |
| WebGL2 | 将 GLSL 的矩阵声明拆分，防止与引擎视图统一缓冲重复声明。双后端使用同套程序化海岸、海面、云层与天空。 |
| 清晰度 | 将 DPR、像素预算、硬件缩放与 DOM UI 解耦。采用 MSAA 和材质各向异性过滤。自动画质先调云层、远景和特效开销，最后有限调整内部像素数。 |
| 灯光 | 统一太阳方向与物理材质曝光。纠正迁移后方向灯的局部轴，恢复落日和地面的对应关系。 |
| 机库 | 沿用 Blender 机库骨架，重新接入混凝土颜色、法线及 ORM，增加接触阴影和室外三维地貌，逐个播放三组起落架的独立旋转。 |
| 地形与碰撞 | 使用 V9 高程和近岸深度资料。沿用同源地表碰撞和遮挡，新增分块边缘遮裙。风暴海浪调整同步到水面碰撞。 |
| 战斗逻辑 | 空战继续使用原有战机、武器、存档、装备、科技及奖励流程。 |
| 历史记录 | V9 可由 Git 标签 `pixel-sky-world-forge-baseline` 恢复。旧检查脚本由适配 PlayCanvas 的 Chromium 交互脚本取代。 |
