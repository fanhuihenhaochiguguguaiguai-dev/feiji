# 《苍穹锋刃》V10 稳定性与画面验收

V10 从 V19.0.2 延续 Babylon.js 8.56.2 渲染及原有空战、装备、存档架构。版本按要求命名为 V10。

## 黑屏故障路径

| 已复现或确认的路径 | 修复与验证 |
| --- | --- |
| `requestAdapter()` 一直挂起会阻止候选后端切换。 | 给 WebGPU 初始化设 9.5 秒时限。注入永不返回的适配器后，Chromium 加载 WebGL2 并正常显示机库。 |
| 原启动界面在真正绘制成功前消失。 | 大厅与出击保留遮罩，直到相机和可见网格可用且已提交实际绘制。前台无帧和启动超时有独立监控。 |
| WebGPU 设备丢失、WGSL 编译错误或 WebGL2 上下文丢失无法从界面恢复。 | 实际销毁 GPU 设备、编译无效 WGSL、调用 WebGL2 掉线扩展。前两项到达兼容 WebGL2，第三项在上下文持续掉线后进入 WebGL2 安全模式。可恢复的 WebGL2 上下文交由 Babylon 先恢复。 |
| 入口脚本返回 HTTP 200 但内容是旧 HTML，或首张地貌返回 404。 | 独立启动壳提供重新连接和安全模式。浏览器注入两种响应后，解除阻断并点重连均返回大厅，旧存档信用点和战役进度保持。 |
| 缓存可能留下一批不完整文件，或在新版激活时移除旧标签仍需的分块。 | 启用前验证整组文件，资源请求绑定发布版本，缓存替换保留一个前代的哈希分块。Node 用缺失分块、HTML 伪装和断网回放验证缓存逻辑。 |
| 机库贴图和附加图形路径可放大低端机图形故障。 | 根据实际浮点能力启用 HDR 后处理。安全模式保留基础三维、PBR 和玩法，关掉可选后处理、级联阴影和 GPU 水雾。KTX2 解码有时限，超时使用源贴图。 |

修复位置 `src/main.ts`、`src/scene-runtime.ts`、`src/startup.ts`、`src/engine.ts`、`src/renderer.ts`、`tools/package.mjs`。

## 视觉改动

- 天空与海洋共用冷青暗部、受控暖色高光的色彩曲线。海水改变漫反射与地平线的色彩比例，保留夕阳镜面高光和原有掠海白沫。
- 机库使用 ACES、HDR 环境探针和冷色轮廓光。压低机坪亮斑，分离金属、座舱玻璃和跑道粗糙度。三维画面独立于文字和 HUD 分辨率。
- 海岸在镜头定位时优先铺出远处地形的粗网格，随后沿用原有四叉树细化。暂停时可继续补齐地貌，战斗时间仍由飞机模拟决定。
- 导航、任务面板、雷达、设置和交易反馈共用深海蓝、枪灰与深青色。保留金色出击、琥珀色锁定和红色告警的用途。

## 运行结果

- TypeScript 和正式打包通过，预缓存清单包含 357 个文件。31 项 Node 回归通过。WebGPU 和 WebGL2 均显示机库、海岸和座舱，完成航炮发射并返回大厅，两个后端均载入两种本地 KTX2 纹理。
- 关闭 WebGL2 后重启进入安全模式。让 WebGL2 上下文恢复时，原页面继续渲染。诊断版恢复后曾出现 GPU 计时查询的旧上下文警告，正式构建中未启用该诊断计时。
- 禁用两类可用设备后，游戏停在错误提示和重连按钮，未重复刷新。
- 最终构建通过第三章空战、章末王牌、自由空战第二波以及重开强度变化。双指追踪期间同时爬升和发射航炮，备弹由 510 降至 498。约 10 米掠海记录到 189 个海面泡沫样本。

## 验证边界

浏览器验收使用 Chromium 与 SwiftShader，800×360 横屏触控视口。故障用可复现的设备、Shader 和 HTTP 响应注入。预览守护进程的端口绑定被环境拒绝，项目浏览器测试使用静态构建夹具，缓存事务使用 Node 检查。未接入出问题的安卓设备，尚未确认该设备的驱动表现、温度、长期稳定性与实际帧率。需要重启渲染的故障会返回机库，已经保存的存档保留，当前未结算出击从头开始。
