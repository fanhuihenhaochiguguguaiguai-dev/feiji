# V18.0.0 缺口精修和运行验收

基线为 `v18-in-place` 的 `8b50c1a`。测试构建只写入临时目录。所有场景沿用现有战机、地图和武器资产。并行提交 `2775799` 移除了独立掉头键，合并后左列保留反制、加速与躲避。声音、右侧大厅入口和版本编号沿用原工程。

## 双后端和性能口径

Chromium 156 运行在 Linux 上，由 SwiftShader 渲染。800×360 CSS 视口，同画面对比锁定 1600×720 输出和 0.66 三维渲染倍率。本地首帧耗时不代表移动设备网络加载时间。

WebGL2 的 SMAA 和 WebGPU 的时域抗锯齿及上采样均触发实渲染。两者都实测了 1600×720、2000×900、2400×1080 和 3200×1440，并切换了 60/90 FPS 目标。最终的机库、三架敌机交战、座舱和命中样板在两个后端均完成渲染，未记录到控制台错误。WebGPU 实际绘制了 50% 的双档过渡，也渲染了由受损副翼产生的独立碎片。WebGL2 在慢帧压力下将三维倍率降到 0.48。慢帧统计现在记录超过 800 ms 的帧间隔，保留对长时间挂起的处理。

| 测试 | 结果 |
| --- | --- |
| 远景机模开关 | 约 3.4 公里处，隐藏三架远机使 WebGPU 场景三角形计数从 202,674 降到 197,424。帧间隔中位数正常两组为约 1203 和 1161 ms，隐藏组约 1209 ms。WebGL2 的两组正常结果包住了隐藏组结果。软件环境未显示可复现收益，本轮保留三维 LOD。 |
| 对照成本 | 固定倍率 WebGL2 同一静态机位，9 个间隔中位数为基线 1171 ms、精修 1205 ms。这一组记录来自最终深度格式校正前的固定倍率样板。样本不能支持帧率提升结论。 |
| 低空压力段 | WebGL2 软件环境在海岸外的雷雨空域连续运行 65.6 秒墙钟时间，推进 20.8 秒游戏时间，飞行约 5.73 公里，发射 85 发航炮和 21 枚导弹，触发 29 次爆炸事件。测试结束时仍在飞行，无控制台错误。JS 堆约 144.0 至 143.8 MB，引擎图形资源约 144.49 至 144.44 MB。这段观测不代表长期内存上限。 |
| 资源口径 | WebGPU 实测图形资源统计约 227 至 282 MB，WebGL2 约 208 至 242 MB。统计来自引擎分配计数，涵盖不同分辨率和渲染倍率。天气实例用约 5.9 KB 静态缓冲，取消旧降水批次每次更新约 4.2 KB 的矩阵上传。测试构建的主脚本 gzip 体积从约 759.2 KB 到 764.2 KB。 |
