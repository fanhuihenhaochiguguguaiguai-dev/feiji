# 苍穹锋刃 V14 工程与美术记录

## 根因和修复

| 实际表现 | 根因 | 修改 |
|---|---|---|
| 大厅战机偏小，机坪和远景平淡 | 大厅与机库共用检视构图。远景采样范围落在低丘和海面，探针亮部、地面纹理、太阳参数各自独立 | 为大厅设置按宽高比调整的低机位。以同一太阳方向制作照明探针和湿机坪灯光，重组机库、塔台和展示区的空间。补充机库灯具、地勤牵引车与分层远山 |
| 新机库试布置中机身被侧墙遮住，远景出现陡截面 | 侧墙进入镜头至飞机的空间，地形网格从高处直接开始 | 机库前沿移出展示区，近岸和网格两侧连续衰减至海面。回到相同横屏比例检查 |
| 战役司令部的地图模糊，跨战区选关会替换整张地图 | 原版使用 512 像素高度色块图铺满视窗，关卡位置按数组索引计算 | 带真实海岸和地貌的全球图固定在左侧，采用太平洋居中的 WGS84 经纬度映射。关卡、航线和经纬网共用坐标，选关只更新聚焦和任务详情 |
| 任务奖励预览缺少首胜状态 | 预览和实际入库各写一次，重复出击仍展示可获首胜材料 | 司令部和结算共用首胜材料定义，显示已入库状态，难度倍率读取出击配置 |
| 大厅显示多个同去处的按钮 | 两侧菜单、顶栏和底部导航分别列出同一功能 | 任务与活动集中到左侧，设置保留于底部，右侧进入战役司令部。底部出击直达当前任务准备，同时提供直接进入武器与仓库的入口 |
| 击毁时弹出两条同义通知，部分落点都像金属命中 | 命中回调和击毁统计分别发通知，地面特效忽略碰撞材质 | 击毁提示由统计更新驱动。曳光及爆炸的尘浪、碎片、水雾根据碰撞材质和入射方向生成 |
| 更新后首轮进入可能读到上一版机库 | 旧离线缓存按版本内固定路径返回文件 | 机库 GLB 与黄昏探针使用新发布路径，旧缩略图与缓存引用随构建清理 |

## 视觉规范与资源

- 大厅以战机、机场远景和三边功能带组织画面。金色标记出击与选中内容，深蓝和冷银保留较宽的场景留白。信用点使用现有专用图案并读取原始档案余额。
- 实时战机继续使用专属 GLB、贴图和机械件。调校公共蒙皮、座舱和采样参数。机库、灯具和牵引车通过 Blender 4.3.2 修改并导出，发布模型经过 glTF Transform、Meshopt 压缩。机坪由环境反射、粗糙度、法线和烘焙灯光共同表现湿面。
- 高度分层云与天空采用 PlayCanvas 中共享的 GLSL 和 WGSL 源。战斗使用原有高度，基地使用低云层参数。战机 UI 和文字继续使用与三维分辨率独立的布局。
- 全球图以 Natural Earth 海岸和地表阴影为源。关卡的经纬度属于虚构任务标记。司令部详情及出击准备分别使用由实战 `.height` 生成的战区地形图。
- 关卡使用蓝银可挑战、青银已完成、低饱和灰未解锁、鎏金当前选中四种状态，锁定徽章仍可点击查看简报而不能出击。

## 文件

- `src/renderer.ts`、`src/shading.ts`、`src/aircraft-materials.ts` 和 `art/hangar.py` 管理展示及环境。
- `src/campaign-chart.ts`、`src/interface.ts`、`src/profile.ts`、`src/v7-ui.css` 管理地图、实际关卡数据及界面。与指挥中心同源的实战地图生成器在 `art/campaign_charts.py`。
- `src/sortie.ts`、`src/combat-art.ts` 根据真实发射和命中事件调度分层视觉反馈。飞行动力、存档键和装备数值沿用原版本。

## 当前范围与质量差距

本轮重点重建大厅及战役司令部，并修复共用材质、命中特效与界面问题。机库资产已重新导出。现有机队使用已有 GLB 结构，不包含逐机重拓扑或重新烘焙。目标图的云层细节、地面实时镜像和近景蒙皮微细节仍高于本版。未测安卓实体设备性能。
